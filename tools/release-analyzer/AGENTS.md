# release-analyzer

Analyzes release history for the release-timeline visualization.

* **Audience:** maintainer. **Lifecycle:** active. **npm:** not published.
* Repository-wide rules are in [the root AGENTS.md](../../AGENTS.md). The [repository index](../../docs/repo-index.md) lists every project.

## Commands

```bash
moon run release-analyzer:test
moon run release-analyzer:dev
pnpm --filter release-analyzer test
```
