# ios-override-importer

One-time importer for the Spectrum iOS override log. Retains its CI target.

* **Audience:** maintainer. **Lifecycle:** one-time. **npm:** not published.
* Repository-wide rules are in [the root AGENTS.md](../../AGENTS.md). The [repository index](../../docs/repo-index.md) lists every project.

## Commands

```bash
moon run ios-override-importer:test
```

## Notes

One-time importer. Keep its CI test target until the import is confirmed complete.
