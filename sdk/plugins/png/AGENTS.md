# sdk/plugins/png

PNG scene renderer: pure-Rust rasterizer, font discovery and the bundled fallback font.

* **Audience:** consumer. **Lifecycle:** active. **npm:** not published.
* Repository-wide rules are in [the root AGENTS.md](../../../AGENTS.md). The [repository index](../../../docs/repo-index.md) lists every project.
* Font rules (what may be bundled, how a font is chosen) are in [the CLI notes](../../cli/AGENTS.md#png-rendering-and-fonts). The plugin model is in [PLUGINS.md](../PLUGINS.md).

moon run sdk:build
