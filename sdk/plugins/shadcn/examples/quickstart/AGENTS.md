# sdk/plugins/shadcn/examples/quickstart

Vite, React and Tailwind v4 example app that applies the Spectrum shadcn theme to Button and Badge.

* **Audience:** demo. **Lifecycle:** active. **npm:** not published.
* Repository-wide rules are in [the root AGENTS.md](../../../../../AGENTS.md). The [repository index](../../../../../docs/repo-index.md) lists every project.
* `npm run setup` generates `spectrum-theme.json` and `src/components/`, both gitignored. Don't commit them or the changes `setup` makes to `src/index.css`.
* `src/spectrum-mapping.css` is hand-written; the rest of the theme is generated by `design-data export --format shadcn-theme`.
