Revised the draft anatomy of the components added in the previous change. Shadows, borders and
strokes are now styling on a part, not parts (new line in the anatomy format chapter). Added the
`prefix` and `opacity-checkerboard` anatomy terms. The required-field indicator is now declared
only on `field-label` (as `necessity-indicator`, renamed from `asterisk`), and the color
handle, loupe, slider and wheel, popover, tabs, segmented control, thumbnail, avatar, toast,
help-text and alert-dialog drafts follow what React Spectrum, Spectrum Web Components and the S2
Web Figma file draw. `tabs` and `segmented-control` now declare a `keyboard-focus` state, and
`segmented-control` a `disabled` state.
