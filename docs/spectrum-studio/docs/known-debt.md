# Known debt

The single list of gaps, debt, redundancy and inconsistency found in the codebase
that are not yet fixed. Agents add, surface and remove items here (see Working
rule 5 in `AGENTS.md`). This is not the design-data gap register
(`src/data/design-data-gaps.json`), which tracks alignment with design-data.

Each item: **ID**, domain, what and where, why it matters, intended fix. Remove an
item when it is fixed and its check passes; do not mark it done and leave it.
