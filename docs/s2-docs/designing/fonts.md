# Fonts

## Spectrum fonts

For design, these fonts are pre-installed on Adobe’s enterprise Figma account. For implementation, look for these in Adobe Fonts (formerly Typekit). If neither of those options support your use case, these fonts are available for download here. View Using restricted Adobe fonts for more information.

### Page last updated: July 31, 2026

### Adobe Clean Spectrum VF

Adobe Clean Spectrum VF is Spectrum’s primary typeface and an update to Adobe Clean, with more modern metrics for usage in UI and product design. It can be used for Latin-based languages as well as Greek and Cyrillic scripts. Download font

### Adobe Clean Spectrum Serif VF

Adobe Clean Spectrum Serif VF is a companion font to Adobe Clean Spectrum VF, for usage in UI and product design. It can be used for Latin-based languages as well as Greek and Cyrillic scripts. Download font

### Adobe Clean

Adobe Clean is Adobe’s corporate typeface. It can be used for Latin-based languages as well as Greek and Cyrillic scripts. Download font

### Adobe Clean Serif

Adobe Clean Serif is a companion font family to Adobe Clean. It covers most Latin-based languages as well as Greek and Cyrillic scripts. Download font

### Source Code Pro

Source Code Pro is used to display code snippets, either inline with another typeface or as a standalone block. Download font

### Adobe Clean Han

Adobe Clean Han is a version of Adobe Clean supporting ideographic scripts – Chinese (Simplified and Traditional), Japanese, and Korean. Download font

### Adobe Clean Thai

Adobe Clean Thai is used for setting the Thai script, in both looped and loopless styles. Download font

### Adobe Clean Arabic

Adobe Clean Arabic is used for the Arabic language, as well as other languages using the Arabic script, such as Persian. Download font

### Adobe Clean Hebrew

Adobe Clean Hebrew is used for modern Hebrew typesetting. Download font

### Adobe Clean Devanagari

Adobe Clean Devanagari supports the Devanagari script, which is used for Hindi and Marathi languages. Download font

## Brand fonts

These resources are restricted fonts for the exclusive use of Adobe products and software. They should only be used through Adobe Fonts (not self-hosted). For instructions, view Using Adobe Fonts at Adobe .

### Adobe Clean Display

Adobe Clean Display is a companion typeface to Adobe Clean, and is mostly used for branding and marketing experiences. It is available only for Latin-based languages. For more information about using Clean Display in Marketing applications, view Usage guidelines in the RED Brand book . Adobe Clean Display is available through Adobe Fonts. For instructions, view Using Adobe Fonts at Adobe .
